# Run your backend on Vercel — Southerly Media walkthrough

Interactive, simulated walkthrough for a Vercel sales demo: a fictional ANZ media company moves its Python pricing API, ffmpeg media service and Celery queue worker next to its Next.js storefront on Vercel.

- Live: https://backend-on-vercel-walkthrough.vercel.app
- Stages: The issue → One repo → One git push → Preview the change → One dashboard → Before / after
- `TALK_TRACK.md` — 2–3 minute spoken script, stage by stage
- `LINKEDIN_CAPTION.md` — short caption

All data is simulated example data. Southerly Media is fictional.

```bash
npm install
npm run dev
```
